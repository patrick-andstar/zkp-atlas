有限域：所有运算发生的那个圈

ZKP 里的每一个数字，都不是普通整数，而是「模一个大素数」之后的余数。 加法会绕回来，除法根本不存在 —— 你得乘逆元。这一页把这件事说到你能手算。

入门必读 ≈ 12 min 难度 2 / 5 前置：00 · 03 环与域 被用于：算术化 · 椭圆曲线 · 配对

01这个模块要解决什么问题

如果用普通整数做证明系统，会有两个致命问题：数字会无限增长， 以及无法隐藏任何东西。

第一个问题：电路里做一百万次乘法，结果会有几百万位。证明者算不动，验证者也存不下。

第二个问题：整数运算可逆且无噪声。给定 a·b = c，很容易反推。 密码学需要「单向」的结构，而整数乘法不是。

有限域同时解决这两件事：所有值都被限制在 0…p−1 之间（固定大小）， 而模运算带来的「绕回」性质让某些问题（离散对数）变得极难。

i
一个必须接受的取舍

域元素没有「大小顺序」，也没有「小数」。所以电路里比较两个数的大小、 判断是否溢出，都不能直接做 —— 必须拆成比特或者查表。 这是后续所有工程复杂度的源头。

?
如果「域」这个词本身就没画面

先绕去 00 · 03 环与域。 那页从「为什么一个运算不够用」讲起，把群 → 环 → 域的层级、零因子、 素数为什么关键全部摊开，每一步配手算。回来再读这页会顺得多。
顺带一提：00 · 04 单位根 解释了下文第 06 节的 ω 到底是个什么东西。

02直觉：钟表算术，但表盘大小是素数

12 小时制的钟：现在 10 点，过 5 小时是 3 点，不是 15 点。这就是「模 12」。

10 + 5 = 15 ≡ 3 ( mod 12 ) ≡ 读作「同余于」，意思是两边除以 12 的余数相同

有限域就是把表盘大小换成一个大素数 p。所有加减乘都在这个表盘上转圈。

为什么必须是素数？因为如果表盘大小是合数（比如 12），有些数就没有逆元 —— 比如 6 在模 12 下，无论乘什么都不会等于 1。而素数表盘上，每个非零数都有逆元。 这条性质叫「域」，是后面一切代数操作的前提。

表盘大小3 有逆元吗6 有逆元吗
12（合数）没有（3·4=12≡0）没有
7（素数）有，是 5（3·5=15≡1）有，是 6（6·6=36≡1）
13（素数）有，是 9（3·9=27≡1）有，是 11（6·11=66≡1）

03定义与符号：把话钉死

𝔽p = { 0, 1, 2, …, p−1 }   配两种运算  + , ×  ( mod p ) p 必须是素数；这个集合加上模运算构成一个「域」
符号含义在 ZKP 里的典型值
p域的特征，一个素数。所有运算的结果都在 [0, p) 内。BN254 的基域约 254 位
𝔽p含 p 个元素的有限域，也叫素域。—
𝔽p*去掉 0 之后的乘法群，含 p−1 个元素。所有非零元都能求逆
a−1a 的乘法逆元，满足 a·a−1 ≡ 1。「除法」就是乘它
ord(a)a 的阶：最小的正整数 k 使 ak = 1。生成元的阶等于 p−1

三条必须记住的运算规则

( a + b ) mod p   ← 加完取余，结果仍在 [0,p)
( a · b ) mod p   ← 乘完取余
a / b  :=  a · b−1 mod p   ← 没有除法，只有乘逆元

04逆元：为什么「除以 3」等于「乘以 5」

这是初学者最常卡住的一步。在 𝔽7 里，1/3 不是 0.333，而是 5。 因为 3 × 5 = 15 ≡ 1 (mod 7)。

手算逆元：扩展欧几里得

要求 3−1 mod 7，就是要找 x 使 3x ≡ 1 (mod 7)。

7 = 2 × 3 + 1   ← 用 7 除 3，余 1
3 = 3 × 1 + 0   ← 用 3 除 1，余 0，停
回代：1 = 7 − 2×3  ⟹  −2×3 ≡ 1  ⟹  x ≡ −2 ≡ 5 ( mod 7 )

验证：3 × 5 = 15 = 2×7 + 1 ≡ 1 ✓

更快的办法：费马小定理

ap−1 ≡ 1 ( mod p )   ⟹   a−1 ≡ ap−2 ( mod p ) 对任意 a ≠ 0 成立（p 为素数）

所以在 𝔽7 里 3−1 = 35 = 243 = 34×7+5 ≡ 5，和上面一致。 实际实现用快速幂，O(log p) 次乘法。

!
电路里的坑

写 a / b 时，如果 b = 0，逆元不存在，结果是未定义的。 所以任何除法都必须额外约束 b ≠ 0，或者改写成 a = c·b 的双向约束。这是真实电路里非常常见的漏洞。

05扩域：为什么配对需要 𝔽p² 和 𝔽p¹²

有些方程在 𝔽p 里无解，但在「更大的域」里有解。 最典型的是 x² + 1 = 0：在实数里无解，引入 i 就有解了。

有限域里做同样的事：把 𝔽p 扩成

𝔽p² = { a + b·u  |  a,b ∈ 𝔽p } ,   其中 u² = −1 每个元素是一对 (a, b)，加法逐分量，乘法按 u² = −1 展开

元素个数从 p 变成 p²。同理可以继续扩到 𝔽p⁶、𝔽p¹²。

为什么 ZKP 需要它

双线性配对的目标群是 𝔾T，它同构于 𝔽p¹²* 的一个子群。 没有扩域就定义不出配对，也就没有 KZG 和 Groth16。

域元素个数在 ZKP 里的角色
𝔽pp曲线坐标、电路约束的取值域
𝔽p²p²G2 群的坐标（每个点两个分量）
𝔽p⁶p⁶配对计算的中间层
𝔽p¹²p¹²配对的目标群 GT

062-adicity：为什么电路规模总是 2 的幂

你可能注意到，ZKP 项目的电路大小总是 220、224 这种数字。 这不是习惯，是域的性质决定的。

FFT/NTT 需要一个「长度为 n 的单位根」，也就是一个元素 ω 使 ωn = 1 且 n 是 ω 的阶。而 𝔽p* 是循环群，阶为 p−1。

把 p−1 分解成 2s · t（t 为奇数），这个 s 就叫 2-adicity：

p − 1 = 2s · t   ⟹   最大支持 n = 2s 的 FFT s 越大，单次能处理的电路规模越大
曲线 / 域2-adicity意味着
BN254 标量域约 28单次 FFT 最多 228 ≈ 2.7 亿个点
BLS12-381 标量域32最多 232 ≈ 43 亿个点
某些为 FFT 优化的域可达 40+为超大规模电路设计

如果电路规模不是 2 的幂，就要补零到最近的 2 的幂 —— 这会浪费最多一半的容量。 所以编译器通常会把电路 padding 到整幂。

i
这也是「域」和「曲线」要配对选的原因

BN254 的基域和标量域 2-adicity 都不错，所以它成为以太坊生态的默认选择。 如果你选了一条 2-adicity 只有 10 的曲线，电路规模会被卡死在 1024，基本没法用。

07完整手算一遍

在 𝔽11 里算 (7 × 8 + 3) / 5。

1

先算乘法

7 × 8 = 56，56 mod 11 = 1（因为 5×11=55，余 1）。

2

再加 3

1 + 3 = 4。

3

求 5 的逆元

要找 x 使 5x ≡ 1 (mod 11)。试一下：5×9 = 45 = 44+1 ≡ 1，所以 5−1 = 9。

4

乘逆元

4 × 9 = 36，36 mod 11 = 3（33+3）。

验算：3 × 5 = 15 ≡ 4 (mod 11)，和第二步的结果一致 ✓

✓
注意这里发生了什么

(7×8+3)/5 在普通算术里是 59/5 = 11.8。 在 𝔽11 里答案是 3。 同一个表达式，不同的数系，完全不同的结果。 读论文时看到「除以 5」，必须知道它在哪个域里。

08小结与常见误区

你应该带走的

  • 所有运算都在 mod p 下进行，结果永远落在 [0, p)。
  • 没有除法，只有乘逆元：a/b := a·b−1。
  • 逆元用扩展欧几里得求，或用费马小定理 ap−2。
  • 扩域 𝔽p²、𝔽p¹² 是配对存在的必要条件。
  • 2-adicity 决定单次 FFT 能处理的电路规模，是选曲线的硬指标。
✕「有限域就是取模运算，和编程里的 % 一样。」
✓
取模只是表示。域还要求每个非零元有逆元、满足分配律等公理。 用合数取模（比如 mod 12）就不是域，因为很多元素没有逆元。
✕「负数在域里不存在。」
✓
−3 在 𝔽11 里就是 8。 域里没有「负号」，只有「加法逆元」。写 −a 时，实际计算的是 p−a。
✕「域元素可以比较大小。」
✓
不能。𝔽p 上没有全序 —— 「5 比 3 大」在域里没有意义。 电路里做 < 比较，必须先把数拆成比特，或者用查找表。
✕「p 越大越安全，所以随便选个大素数就行。」
✓
还要看 2-adicity（决定 FFT 规模）、是否配对友好（决定能否做 KZG）、 以及生态支持（以太坊预编译只认 BN254）。选错域，后面全部要重来。
