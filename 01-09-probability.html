概率与抽样：随机验一点，凭什么等于验了全部

SNARK 的验证者只看一个随机点，就敢相信一个覆盖上亿条约束的等式成立。 这不是工程上的偷懒，而是一个可以严格证明的引理 —— 整个 ZKP 的可靠性，最后都落在这个概率界上。

可靠性基石 ≈ 12 min 难度 2 / 5 前置：多项式 被用于：QAP · FRI · 所有抽查

01这个模块要解决什么问题

验证者拿到了一个等式 P(x) = h(x)·Z(x)，其中 P 的次数是 106。 他要在不读全部系数的情况下判断这个等式是否恒成立。

有两种办法：

  • 逐个系数比对：O(n)，等于把证明重新算一遍，毫无意义。
  • 随机取一个点 z，检查两边是否相等：O(1)，但可能漏检。

关键问题是：漏检的概率有多大？ 如果这个概率可以被压到 2−100 以下， 那它就比「硬盘静默损坏」更可靠。

02直觉：一个多项式能「装」多少个零点

想象一条抛物线（2 次多项式）。它最多与 x 轴相交 2 次 —— 这是中学知识。 一条 100 次曲线最多交 100 次。

d 次非零多项式  ⟹  最多 d 个根 这条「代数基本定理」的推论，就是全部安全性的来源

现在把这条曲线放在一个有 p ≈ 2254 个点的数轴上。 随机戳一个点，戳中根的概率最多是 d / p。

当 d = 106、p = 2254 时， 这个概率约等于 106 / 1076 = 10−70 —— 比连续中一百次彩票还难。

i
为什么不是「验证者要相信证明者」

因为这里没有信任：证明者无法预测验证者会选哪个点。 如果等式不成立，那个「差值多项式」必然非零，而它只有有限个根。 证明者想让验证者踩中根，得猜中随机数 —— 概率就是上面那个数。

03Schwartz–Zippel 引理：正式版本

单变量版本很好懂。多变量版本才是 ZKP 里真正用到的形式。

引理：设 P(x1,…,xn) 是一个非零多项式， 总次数为 d。S 是一个有限集合。
若 r1,…,rn 独立均匀地取自 S，则
Pr[ P(r1,…,rn) = 0 ]  ≤  d / |S| 这是最常用的形式；更精确的版本会带一个小的修正项
符号含义在 ZKP 里是什么
P「差值多项式」。如果命题成立，它恒为零(ΣwA)(ΣwB) − ΣwC − hZ
d总次数约等于电路规模 m
S抽样范围整个 𝔽p，大小约 2254

注意前提：P 必须非零。如果证明者作弊导致 P ≠ 0， 那么它最多有 d 个根，随机点落在根上的概率就是 d/|S|。

04证明思路：对变量个数做归纳

单变量情形就是「d 次多项式最多 d 个根」。多变量用归纳：

1

把 P 看成最后一个变量的多项式

P(x₁,…,xₙ) = Σi ci(x₁,…,xn−1)·xni， 其中系数本身是前 n−1 个变量的多项式。

2

先固定前 n−1 个变量

对随机取定的 r₁…rn−1，P 变成关于 xn 的单变量多项式， 次数不超过 d。它要么恒为零，要么最多 d 个根。

3

再对最后一个变量抽样

「恒为零」这种情况只在前 n−1 个变量恰好落在某个低次曲面上时发生 —— 由归纳假设，这个概率不超过 d/|S|。 其余情况下，再抽 xn 踩中根的概率也不超过 d/|S|。

两步合起来，总失败概率不超过 2d/|S|。经过更精细的分析可以去掉系数 2， 得到 d/|S|。

i
为什么工程上从来不关心这个常数

因为 d/|S| ≈ 2−240，前面乘 2 还是乘 10 都无所谓。 安全裕度大到可以忽略常数因子，这是密码学里少见的舒服情况。

05可靠性误差：把「漏检」算成一个数

SNARK 的安全性通常表述为「可靠性误差 ≤ ε」。这个 ε 就是 Schwartz–Zippel 给出的概率。

ε  =  d / |𝔽p|  =  d / p d 是约束条数，p 是域大小

代入真实数字

电路规模 d域大小 p可靠性误差 ε等效安全位数
210 ≈ 1 千22542−244244 位
220 ≈ 100 万22542−234234 位
228 ≈ 2.7 亿22542−226226 位

即使电路大到 228，安全裕度仍有 226 位 —— 远超 128 位的工程标准。 所以单点验证在数学上完全够用，不需要重复。

!
但这个界只在「P 非零」时有用

如果证明者能构造出 P ≡ 0 但命题为假的情况（比如电路约束写漏了）， Schwartz–Zippel 帮不了你 —— 它只管「等式是否恒成立」，不管「等式是否表达了你想表达的东西」。 这就是「算术化正确性」和「密码学可靠性」的分界线。

06多次抽样：并集界

有些协议（比如 FRI）要抽多个点。失败概率怎么算？

Pr[ 至少一次踩中 ]  ≤  Σi Pr[ 第 i 次踩中 ]  =  q · d / p 并集界（union bound）：概率最多线性累加

这里 q 是抽样次数。因为每次的概率都是 d/p， 总量最多是 q·d/p。

FRI 里的形式不一样

FRI 的失败概率是 (1−δ)q，指数衰减而不是线性累加。 因为每一次查询都在「独立的层」上，且每层都有一定的「远离度」δ。

FRI：Pr[ 漏检 ] ≤ ( 1 − δ )q   vs   QAP 单点：Pr[ 漏检 ] ≤ d/p 前者靠「多次独立抽查」，后者靠「域足够大」

两种机制都是「把概率压到可忽略」，但路径不同：一个用重复，一个用大空间。

07手算一个具体概率

假设某个证明系统用了一个「小域」，p = 65537（约 216），电路有 1000 条约束。

ε = 1000 / 65537 ≈ 0.0153 约 1.5% —— 每验证 65 次就有一次可能被蒙混过关

这完全不可接受。 所以真实系统绝不用小域。

换成 p ≈ 2254：

ε = 1000 / 2254 ≈ 2−244 约 10−73 —— 可忽略
✓
这就是为什么「域要足够大」不是可选项

域太小，Schwartz–Zippel 的界就松到没有意义。所有实用 SNARK 的域都在 254 位以上， 不是为了「更安全」，而是为了让这个概率界成立。

08小结与常见误区

你应该带走的

  • d 次非零多项式最多 d 个根 —— 这是所有抽查的理论基础。
  • Schwartz–Zippel：Pr[P(r)=0] ≤ d/|S|，对多变量也成立。
  • QAP 的可靠性误差就是 d/p，代入真实数字后是 2−240 量级。
  • 多次抽样用并集界：q·d/p；FRI 则是指数衰减 (1−δ)q。
  • 域太小会让这个界失效，所以实用系统都用 254 位以上的域。
✕「随机抽查是工程上的妥协，不严谨。」
✓
恰恰相反，它是可证明的。Schwartz–Zippel 是定理，不是启发式。 而且失败概率比大多数工程系统的物理故障率还低。
✕「多验几个点一定更安全。」
✓
当 d/p 已经是 2−240 时，再乘 3 变成 2−238 —— 没有实际意义。真正的风险在电路写错、仪式泄露、实现漏洞，不在这个概率上。
✕「Schwartz–Zippel 能保证电路是对的。」
✓
它只保证「如果差值多项式非零，随机点大概率能发现」。 如果电路本身少了一条约束，差值多项式可能恒为零，此时任何抽样都发现不了。
✕「随机数可以用伪随机生成器代替，效果一样。」
✓
可以，但前提是种子对证明者不可预测。如果证明者能预测验证者的随机点， 他就可以专门构造一个在该点为零、但并非恒零的多项式 —— 整个论证失效。
