# ZKP 技术图谱

零知识证明的三层技术栈 + 一层零基础前置，拆成 **33 个可以单独学完的模块**，每个模块一页。

在线地址：<https://patrick-andstar.github.io/zkp-atlas/>

## 结构

| 层 | 内容 | 页数 |
|---|---|---|
| **00 零基础前置** | 数系地图 / 群 / 环与域 / 根与单位根 / 符号黑话 / 线性代数 | 6 |
| **01 数学基础** | 有限域 / 椭圆曲线 / 配对 / 多项式与 FFT / 编码 / 复杂性 / 哈希 / 承诺 / 概率 | 9 |
| **02 证明构造** | 算术化 / 多项式承诺 / 查找 / 置换 / Fiat–Shamir / 折叠 / 零知识 / 证明系统 / 递归 / Sumcheck / 范围证明 | 11 |
| **03 工程实现** | 电路 DSL / 证明后端 / 可信设置 / 聚合 / 硬件 / 审计 / zkVM | 7 |

## 阅读顺序

- 有数学基础：直接 01 → 02 → 03
- 没有：00·01 → 00·02 → 00·03 → 00·04 → 00·06，00·05 当速查表
- 只缺符号：00·05

## 本地查看

纯静态，无构建步骤。直接打开 `index.html`，或起个本地服务：

```bash
python -m http.server 8000
```

## 部署

推送到 `main` 分支后由 GitHub Pages 直接从仓库根目录发布（`.nojekyll` 已加，跳过 Jekyll 处理）。

## 已知显示问题

本机字体不含 U+1D53D `𝔽` / U+1D53E `𝔾`，这两个字符会退化成普通 `F` / `G`。不影响语义，详见 00·05。
