根：从「方程的解」到「FFT 的燃料」

你在论文里看到的「根」有三种完全不同的意思，混在一起会彻底读不下去。 这一页先分清它们，然后重点讲第三种 —— 单位根， 那个让 FFT 快一万倍、让多项式承诺能落地的 ω。

概念枢纽 ≈ 16 min 难度 2.5 / 5 前置：00 · 03 被用于：多项式与 FFT · KZG · FRI · STARK

01先说清楚：「根」这个词有三种用法

中文把三个英文词都翻成了「根」，这是翻译的锅。读的时候必须看上下文。

英文中文意思例子
root (of a polynomial) 根 / 零点 让 f(x) = 0 成立的 x x²−4 的根是 2 和 −2
root of unity 单位根 让 xⁿ = 1 成立的 x x⁴=1 的根是 1, −1, i, −i
square root / radical 平方根 / 根号 开方的结果 √9 = 3

ZKP 里出现频率最高的是第一种和第二种，而且第二种是第一种的特例。 第三种（开方）只在讲「二次剩余」时出现，可以先不管。

i
还有一个「根」不是这个根

Merkle 树的根哈希（root hash）里的 root 是「树根」，是数据结构概念，和数学无关。 论文里「Merkle root」和「root of unity」同时出现时别搞混。

02根 = 方程的解：最朴素的定义

给定一个多项式 f(x)，「求根」就是解方程 f(x) = 0。

f(r) = 0   ⟺   r 是 f 的一个根 把 r 代进去，算出来是 0

几个你早就知道的例子：

多项式次数根
x − 313
x² − 422, −2
x² + 1（在 ℝ 上）2没有
x² + 1（在 ℂ 上）2i, −i
x² − 4（在 𝔽7 上）22, 5（因为 5²=25≡4）

看最后两行 —— 同一个多项式，在不同的域里根的个数不一样，甚至可能没有。 这是「根」在密码学里最反直觉的地方：讨论根之前，必须先说清在哪个域里找。

03根与因式分解：为什么「根」这么有用

根之所以重要，不是因为「解出那个数」，而是因为它和整除是等价的两件事。

r 是 f 的根   ⟺   ( x − r ) 整除 f(x) 叫「因式定理」，整个 ZKP 的构造逻辑都建立在它上面

举个例子。取 f(x) = x² − 5x + 6，代 x = 2：4 − 10 + 6 = 0。 因为 2 是根，所以 (x−2) 一定整除它：

x² − 5x + 6 = ( x − 2 )( x − 3 ) 除完商是 x−3，余数为 0

反过来，除法有余数时，余数就携带了「这个点上的值」：

用 ( x − r ) 除 f ，余数恒等于 f(r) 叫「余数定理」。余数为 0，恰好说明 r 是根
✓
这就是 KZG 的全部秘密（现在看不懂没关系）

想证明「我知道一个多项式 f，它在点 a 上的值是 v」， 验证者要你交出 q(x) = (f(x) − v) / (x − a)。
如果 v 真的等于 f(a)，那 a 是 f(x)−v 的根， 除法整除，余数为 0，商 q 是个合法的多项式。
如果 v ≠ f(a)，除法有余数，q 就不是多项式 —— 交不出来。
「知道这个点的值」被转化成了「能证明整除」。（02 · 02 展开）

04单位根：让 xⁿ = 1 成立的那些 x

单位根是「根」的一个特例：不找任意多项式的根，只找 xⁿ = 1 的根。

ωn = 1 ω 读作 omega。满足这个式子的 ω 叫「n 次单位根」

为什么叫「单位」？因为右边是 1，也就是乘法的单位元。用 00 · 02 的话说： ω 的阶整除 n。

先在最熟的实数里试：

方程实数里的根说明
x¹ = 11只有一个
x² = 11, −1两个
x³ = 1只有 1−1 的立方是 −1，不是 1
x⁴ = 11, −12 和 −2 立方是 8 和 −8

实数里最多只有两个。但「n 次多项式最多 n 个根」这条定理说最多 n 个 —— 那剩下的去哪了？跑到复数里去了。

05复数单位根长在单位圆上

在 ℂ 里，xⁿ = 1 恰好有 n 个根，而且它们均匀分布在一个圆上。

原因很漂亮：复数可以写成极坐标 r·(cos θ + i sin θ)。 乘法的效果是「模长相乘、角度相加」。要 ωⁿ = 1，就是要求：

模长：rn = 1  ⟹  r = 1   （必须在单位圆上）
角度：n·θ = 360° 的整数倍  ⟹  θ = k·360°/n n 个等分点，转 n 次正好回到起点

图里第二行那个 ωn/2 = −1 值得单独记住（前提是 n 为偶数，奇数 n 时 n/2 不是整数）。 圆上「转半圈」就是乘以 −1，所以后半圈的点永远是前半圈取负。 这个小事实撑起了整个 FFT —— 后面第 8 节会用到。而 FFT 的 n 一定是 2 的幂，全是偶数，所以永远用得上。

i
「本原单位根」是什么

有些 ω 只能转出圆上的一部分点。比如 4 次单位根 i， 它的幂是 i, −1, −i, 1 —— 四个点全走到了，它是本原的。
但 −1 虽然也是 4 次单位根（(−1)⁴=1），幂只有 −1, 1 两个点，不是本原的。
本原 = 阶正好是 n = 生成元。和 00 · 02 的生成元是同一个概念。

06有限域里没有圆，但有同样的东西

这是最容易卡住的一步：𝔽p 里没有「角度」，没有「圆」，单位根长什么样？

答案：不需要长什么样。 单位根的全部用途只有一个 —— 它是 xⁿ = 1 的根，也就是「乘 n 次回到 1」的元素。 这个纯代数性质，在 𝔽p 里完全可以复现。

做法很直接：因为 𝔽p* 是循环群（00 · 02）， 取一个生成元 g，群阶是 p−1。那么：

ω = g(p−1)/n   ⟹   ωn = gp−1 = 1 只要 n 整除 p−1，就一定有 n 次单位根

「只要 n 整除 p−1」 —— 这句话是全部工程约束的来源，下一节展开。

性质在 ℂ 里在 𝔽p 里
ωⁿ = 1✓✓ 一样
ωn/2 = −1✓✓ 一样（n 为偶数时）
n 个根均匀分布在圆上，看得见散落在 0…p−1 里，看不出规律
能画出来能不能（只能画成散点）
代数运算浮点，有误差整数，精确

所以论文里的 ω，你在纸上算的时候可以把它当成「复平面上那个转 1/n 圈的点」来理解 —— 所有代数恒等式完全一样。只有在真正落数值的时候，才换成 𝔽p 里的整数。

✓
一句话

𝔽p 里的单位根，就是「伪装的复数单位根」。 它没有几何形状，但有全部代数功能。FFT 的每一行代码都不关心 ω 长什么样，只关心 ωk 怎么算。

07为什么偏偏要 2 的幂：2-adicity

现在能回答 01 · 01 里那个悬着的问题了：为什么电路规模总是 2²⁰ 这种数？

因为 FFT 是分治算法：每一层把问题对半砍，砍 log₂n 层就到底。 要对半砍，就需要「一半是另一半的相反数」这个性质，也就需要 ωn/2 = −1， 也就需要 n 是 2 的幂。

而你能不能拿到 2s 次单位根，取决于 p−1 里有几个 2：

p − 1 = 2s · t   （t 为奇数） 这个 s 就叫域（或曲线标量域）的 2-adicity。它决定了最大 FFT 长度 2s
域 / 曲线2-adicity能支持的最大 FFT
BN254 标量域282²⁸ ≈ 2.68 亿
BLS12-381 标量域322³² ≈ 42.9 亿
Goldilocks (2⁶⁴−2³²+1)322³²，且是 64 位机器最友好的域
某个随机大素数可能只有 12¹ = 2 —— 基本没法用
!
这就是「选域不是随便挑个大素数」的真正原因

一个随机生成的 254 位素数，p−1 能被 4 整除的概率是 1/2，能被 8 整除是 1/4…… 平均下来 2-adicity 只有 2 左右。
ZKP 用的素数都是专门构造的：先定好要 s = 28，再反解出素数。 这叫「FFT-friendly prime」。选错了，你的电路永远卡在 4 个门。

08FFT 到底靠单位根省了什么

这一节是全页最硬的部分，但只看一个对比就够了。

问题：给一个 n−1 次多项式 f，求它在 n 个点上的值。

笨办法：逐点代入

每个点要算 n 次乘加，n 个点就是 n² 次运算。 n = 2²⁰（约一百万）时，n² 是一万亿次。跑不动。

聪明办法：选特定的点，让计算能对半砍

把求值点选成 1, ω, ω², …, ωn−1。这时会发生一件事：

f(x) = f偶(x²) + x · f奇(x²) 把偶次项和奇次项分开，各占一半 —— 因为 (ωᵏ)² = ω2k

关键在这一步：(ωᵏ)² 只有 n/2 种不同取值（因为 ωk+n/2 平方后和 ωᵏ 一样）。 于是：

f(ωk) = f偶(ω2k) + ωk·f奇(ω2k)
f(ωk+n/2) = f偶(ω2k) − ωk·f奇(ω2k) 两行只差一个符号 —— 算一次能得两个值（这就是 ωn/2=−1 的用处）

递归下去，总复杂度从 O(n²) 变成 O(n log n)。 n = 2²⁰ 时，从一万亿降到两千万 —— 快五万倍。

nn²（笨办法）n log₂n（FFT）倍数
2¹⁰ = 1,024约 100 万约 1 万100×
2²⁰ ≈ 100 万约 1 万亿约 2 千万50,000×
2²⁸ ≈ 2.7 亿约 7×10¹⁶约 7.5×10⁹10,000,000×

这不是「优化」，这是「可做与不可做的分界线」。 没有单位根就没有 FFT，没有 FFT 就没有现代 ZKP。

i
还有个小细节：NTT vs FFT

论文里这两个词混着用。严格说：FFT 指复数上的快速傅里叶变换， NTT（Number Theoretic Transform）指有限域上的同一套算法。 因为 ZKP 只做有限域，实际实现里全是 NTT，但作者常顺手写 FFT。 看到 FFT 就当 NTT 理解，不影响。

09手算：𝔽17 的四次单位根

取 p = 17。p − 1 = 16 = 2⁴，所以 2-adicity = 4，能支持最长 16 点 FFT。 这里只找 4 次单位根，n = 4。

1

确认 n 整除 p−1

4 | 16 ✓。有解。如果 n 不整除 p−1，一个根都没有，别白试。

2

找一个生成元 g

试 g = 3：3¹=3, 3²=9, 3³=27≡10, 3⁴=30≡13, 3⁵=39≡5, 3⁶=15, 3⁷=45≡11, 3⁸=33≡16≡−1。
到第 8 步才出现 −1，说明阶是 16 —— 3 是生成元。

3

算出 ω

ω = g(p−1)/n = 316/4 = 3⁴ = 13。
所以 ω = 13 是 𝔽17 里的一个四次单位根。

4

验证四个根

ω⁰ = 1
ω¹ = 13
ω² = 169 mod 17 = 169 − 153 = 16 ≡ −1 ✓ 正好是「半圈」
ω³ = 16×13 = 208 ≡ 208 − 204 = 4
ω⁴ = 4×13 = 52 ≡ 1 ✓ 闭环

四个根是 {1, 13, 16, 4}。它们在数轴上散得很乱 —— 没有圆，看不出规律。 但它们的代数行为和 {1, i, −1, −i} 一模一样：

复数版𝔽17 版共同性质
11单位元
i13平方 = −1
−116平方 = 1，本身是 −1
−i4平方 = −1
✓
验算一下「半圈」那条性质

ω² = 16，而 −1 = 17 − 1 = 16。完全一致。
这不是巧合：ωn/2 是 x² = 1 的根，除了 1 就只剩 −1。

10小结与误区

你应该带走的

  • 「根」有三种：多项式的根（f(r)=0）、单位根（ωⁿ=1）、开方。ZKP 主要用前两种。
  • 因式定理：r 是根 ⟺ (x−r) 整除 f。余数定理：用 (x−r) 除的余数 = f(r)。KZG 全靠这个。
  • 单位根 = 乘 n 次回到 1 的元素。复数版在单位圆上均匀分布，有限域版是一堆散乱的整数，代数性质完全相同。
  • ωn/2 = −1（n 为偶数时）是 FFT 分治的全部依据。
  • 𝔽p 里存在 n 次单位根 ⟺ n 整除 p−1。不整除就一个都没有。
  • 2-adicity = p−1 里 2 的幂次，决定最大 FFT 长度。这是选域的硬指标。
  • FFT 把 O(n²) 的求值降到 O(n log n)，在 n=2²⁰ 时快约 5 万倍。
✕「𝔽p 里的单位根一定存在。」
✓
不一定。 必须 n | (p−1)。 比如 𝔽7 里 p−1 = 6，所以有 1、2、3、6 次单位根，没有 4 次和 5 次。 这就是为什么电路的「evaluation domain」大小必须先和域参数对齐。
✕「单位根就是复数里那个 e2πi/n。」
✓
那只是一个具体的表示。单位根的本质是「阶为 n 的群元素」， 在任何有足够单位根的域里都存在。论文里用 ω 而不是具体数值，就是为了保持这种抽象。
✕「FFT 是一种近似算法，会有误差。」
✓
FFT 本身是精确的代数恒等式，没有近似。 有误差的是「用浮点实现复数 FFT」。ZKP 用 NTT（有限域版），结果精确到最后一个比特。 这点很重要 —— 验证不能容忍误差。
✕「多项式次数越高越难算，所以要尽量避免高次。」
✓
现代方案（FRI、STARK、Binius）恰恰用极高的次数来换安全性， 靠的就是 FFT/NTT 把高次求值压到 O(n log n)。 真正的瓶颈是证明大小和内存，不是次数本身。
