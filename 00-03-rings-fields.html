环与域：两个运算才够用

群只有一个运算，写不出 3x² + 2x + 1 这种东西 —— 那需要加和乘同时在场。 加上第二个运算，就有了环；再要求「除 0 以外都能除」，才有了域。 而「能不能除」，取决于模数是不是素数。

零基础必读 ≈ 22 min 难度 2 / 5 前置：00 · 02 被用于：有限域 · 多项式 · 全部证明系统

01为什么一个运算不够

群只能做一件事。但 ZKP 的全部内容，几乎都是多项式。

f(x) = 3x² + 2x + 1 这一个式子里，「3x²」需要乘法，「+」需要加法，两者必须同时存在

只给你加法，你写不出 x²。只给你乘法，你写不出 x + 1。 所以必须有一个结构同时容纳两种运算，还得保证它们能互相配合 —— 这个配合规则叫分配律。

a · ( b + c ) = a·b + a·c 展开括号的合法性来源 —— 没有它，多项式根本没法运算

这就是「环」的动机：把两个群缝在一起，再要求乘法能分配到加法上。

02环：加法是群，乘法宽松一点

定义可以拆成三句话读：

要求严格程度说人话
加法构成阿贝尔群最严能加、能减、有 0、可交换
乘法构成半群宽松能乘、结合律成立。不要求有 1、不要求可逆
乘法对加法分配缝合剂能展开括号

注意中间那行的宽松程度：环里的乘法可以没有逆元。 这正是 ℤ（整数）的处境 —— 2 乘什么都得不到 1，但 ℤ 仍然是环。

结构是环吗说明
整数 ℤ是标准范例。有 1，但没有乘法逆元（除了 ±1）
模 12 余数 ℤ12是能加能乘，但 6 没逆元 —— 所以只是环，不是域
模 7 余数 ℤ7是而且更强：它是域
多项式 ℤ[x]是系数是整数、变量是 x 的所有多项式
n×n 矩阵是加法逐项、乘法是矩阵乘。不可交换 —— 所以是「非交换环」

表里第 2 行和第 3 行，就是本页要讲的全部内容 —— 差一个条件，命运完全不同。

03零因子：合数模会烂在哪

在 ℤ12 里算 3 × 4：

3 × 4 = 12 ≡ 0 ( mod 12 ) 两个都不为 0 的数，乘出来是 0

这叫零因子（zero divisor）。它带来的后果比「没逆元」更严重：

!
后果一：约分失效

普通算术里，ac = bc 且 c ≠ 0 ⟹ a = b。
但 ℤ12 里 3×1 = 3，3×5 = 15 ≡ 3 —— 两边都等于 3，但 1 ≠ 5。不能约掉 3。

!
后果二：多项式根的个数失控

域上一个 n 次多项式最多有 n 个根 —— 这是 Schwartz–Zippel 引理和整个 ZKP 概率论证的地基。
但在 ℤ12 里，x² − 1 的根有 四个：1, 5, 7, 11 （因为 1²=1，5²=25≡1，7²=49≡1，11²=121≡1）。
「随机取一个点验证」这套方法直接崩塌。

为什么素数模就没有零因子

假设 p 是素数，且有 a·b ≡ 0 (mod p)，其中 0 < a,b < p。
这意味着 p | a·b。而 p 是素数 —— 一个素数整除一个乘积，就必然整除其中一个因子。

p | a·b  ⟹  p | a 或 p | b 但 a、b 都比 p 小且非零，p 不可能整除它们 —— 矛盾。所以零因子不存在。

这条性质叫「素性」的欧几里得引理。「素数模没有零因子」和「素数模是域」是同一件事的两种说法。

04域：再补一条，全部打通

域 = 环 + 每个非零元都有乘法逆元。加上这一条，四则运算全部封闭。

能力群环域
加法 + 减法✓✓✓
乘法✗✓✓
展开括号✗✓✓
除法（除 0 外）✗✗✓
能解任意一次方程✗✗✓

最后一行值得展开：ax + b = 0 要在集合内有解，就要能算 x = −b/a。 没有除法，这个方程就解不出来 —— 而 ZKP 里每一个约束都长这样。

域的三条「免费赠品」

一旦是域，下面这些性质自动成立，不需要额外假设。它们每一条在后面都会被用到：

  1. 没有零因子 —— 前面证过，是「可除」的等价说法。
  2. n 次多项式最多 n 个根 —— 支撑 Schwartz–Zippel（01 · 09）。
  3. n+1 个点唯一确定一个 n 次多项式 —— 支撑插值和 KZG 的「开口唯一性」。
✓
这三条就是 ZKP 的全部地基

第三条尤其关键：如果同一批点能插出两个不同的多项式，多项式承诺就毫无意义 —— 证明者可以换一个多项式蒙混过关。而「唯一定理」成立的前提，正是系数在域里。

「不能比较大小」不是缺陷，是特性

正因为 𝔽p 里没有大小顺序，攻击者无法通过「这个数看起来更小」来推断秘密。 如果 ZKP 用 ℚ，一个承诺值的「大小」就会泄露信息。
代价是：电路里做 a < b 这种比较，必须拆成二进制位或查表 —— 这就是范围证明存在的原因。

06素域与扩域：从 𝔽p 到 𝔽p²

𝔽p 叫素域（prime field），因为它不能再拆成更小的域。 但域也能「往上长」，方式和 00 · 01 讲的 ℝ → ℂ 一模一样。

1

先看 ℝ → ℂ 是怎么做的

x² + 1 = 0 在 ℝ 里无解。于是硬造一个符号 i， 规定 i² = −1，然后让所有 a + bi 组成新集合。

2

𝔽p → 𝔽p² 照抄这个套路

找一个在 𝔽p 里无解的二次方程 x² = β（β 是非二次剩余）。 硬造符号 u，规定 u² = β，新元素写成 a + b·u。

3

运算怎么算

加法逐分量：(a+bu) + (c+du) = (a+c) + (b+d)u。
乘法展开后把 u² 换成 β：(a+bu)(c+du) = (ac + bdβ) + (ad+bc)u。

4

规模

a 有 p 种取法，b 有 p 种，所以 𝔽p² 有 p² 个元素。 一直往上可以到 𝔽p⁶、𝔽p¹²。

域元素个数在 ZKP 里干什么
𝔽pp曲线坐标、电路里的每个变量
𝔽p²p²G2 群的点坐标（每个坐标占两个分量）
𝔽p⁶p⁶配对计算中的塔式中间层
𝔽p¹²p¹²配对的目标群 𝔾T 住在这里

一句话记住：𝔽p 是「数字」，𝔽p² 是「一对数字」，𝔽p¹² 是「十二个数字捆一起」。 扩域的元素在计算机里就是一个小数组，运算则是按固定公式展开 —— 没有魔法，只是麻烦。

07「特征」是什么：一个被忽视但常考的词

论文里会写「特征为 p 的域」。定义很短：

最小的正整数 n 使  1 + 1 + ⋯ + 1（n 个）= 0 就是把 1 反复相加，第一次加出 0 需要几次

在 ℝ 里，1 加多少次都不会变成 0 —— 所以 ℝ 的特征是 0（约定）。
在 𝔽7 里：1+1+1+1+1+1+1 = 7 ≡ 0 —— 所以特征是 7。

!
这个定义带来的最大冲击

在特征 p 的域里，p = 0。
所以在 𝔽7 里，「7 个 1 加起来等于 0」不是近似，是精确的等式。 论文里写 p · g = 𝒪（椭圆曲线上 p 倍点等于无穷远点）就是这个意思。 初学时看到「p 等于 0」会觉得矛盾，因为它和你熟悉的整数 p 不是同一个对象。

另一个常用推论（Freshman's dream）：

( a + b )p = ap + bp 在特征 p 的域里成立 —— 中间那堆二项式系数全被 p 整除，全归零

正常展开时中间项是 C(p,k)·aᵏ·bp−k，而 C(p,k) 对 0<k<p 都能被 p 整除 —— 在特征 p 里就是 0。这个小技巧在 FRI 和 Binius 的推导里反复出现。

08为什么不用 ℚ 或 ℝ？

既然 ℚ 和 ℝ 都是域，四则运算齐全，为什么 ZKP 非要费劲造一个「有限的域」？

问题用 ℚ / ℝ 会怎样用 𝔽p 会怎样
精确表示 1/3 是无限小数；实现里只能用浮点，有误差 每个元素是 0…p−1 的整数，完全精确
相等判断 浮点下 0.1+0.2 ≠ 0.3，验证结果不可信 整数比较，要么等要么不等
随机采样 连续空间无法「均匀随机取一个数」 从 p 个里等概率抽，可证明的概率界
抗量子/抗分析 实数上的运算可被数值方法逼近反推 离散结构，只能暴力搜
计算速度 大数分数运算极慢 定长整数，硬件原生支持

最关键的是第三行。ZKP 的安全性全是概率性的 —— 「验证者随机挑一个点，如果证明者作弊，被抓到的概率至少是 1 − n/p」。 这句话要成立，前提是「随机挑一个点」这件事在数学上定义得清楚。 连续空间里做不到，有限集合里可以。

✓
一句话总结

用 𝔽p 不是因为「更高级」，是因为只有它能被计算机精确地、可证明地、快速地玩。 数学上 ℚ 更「自然」，工程上 𝔽p 才是唯一选择。

09多项式：ZKP 真正操作的对象

第 04 节说过「n+1 个点唯一确定一个 n 次多项式」，但没讲多项式本身怎么运算。 而 02 · 01 的后半程（QAP）、02 · 02 的全部、01 · 04 的插值，都在拿多项式做加乘除。 这一节补齐。

多项式就是「一串系数挂在 x 的幂上」

f(x) = a0 + a1x + a2x2 + ⋯ + adxd d 叫「次数」，ad ≠ 0。这里的 ai 全是 𝔽p 里的数

关键认知：多项式其实是「把向量竖起来写」。 系数向量 (a₀, a₁, …, a_d) 和多项式一一对应 —— 这就是 01 · 04 说的「两种表示法」之一（系数表示）。

加法：逐系数加，次数取大的

( 1 + 2x + 3x² ) + ( 5 + 0x + 1x² ) = 6 + 2x + 4x²
deg(f + g) ≤ max( deg f , deg g )  ← 可能因为最高项抵消而变小

乘法：每个配每个，次数相加

deg( f · g ) = deg f + deg g 这是最常用的一条 —— 因为它意味着「乘法会让次数膨胀」

手算一个：

( 1 + 2x ) · ( 3 + x ) = 1·3 + 1·x + 2x·3 + 2x·x
                 = 3 + x + 6x + 2x² = 3 + 7x + 2x²

次数：1 次 × 1 次 = 2 次 ✓ 对得上

注意 x 项的系数 1 + 6 = 7 —— 「同类项合并」就是这里的「逐系数相加」。 如果系数在 𝔽p 里，合并后还要取模。

!
为什么 ZKP 怕次数膨胀

电路里有 n 个乘法门，如果每次都把多项式乘一遍，次数会指数爆炸。 这就是为什么 FFT 只做「求值」不做「乘法」，而 02 · 01 的 QAP 要把约束编码成多项式、再用整除来检查，而不是直接展开相乘。
记住这条：「次数」是 ZKP 里最贵的资源，比系数个数还贵。

除法：有商有余，和整数一模一样

多项式的长除法，规则和整数除法完全同构：被除数 = 除数 × 商 + 余数， 而且余数的次数一定小于除数的次数。

用 ( x − 2 ) 除 ( x² − 5x + 6 )：
商 = x − 3 ，余数 = 0  ← 整除，因为 2 是根

用 ( x − 1 ) 除 ( x² − 5x + 6 )：
商 = x − 4 ，余数 = 2  ← 有余数，因为 f(1) = 2

第二行验证了 00 · 04 的余数定理：f(1) = 1 − 5 + 6 = 2，而余数正是 2。 「余数 = 那一点的取值」，这就是 KZG 开口证明的原理。

零点多项式 ZH(x)：一个专门「在该为零的地方为零」的多项式

这是 02 · 01 里最容易被忽略、但绝对不能不懂的构造。

设 H 是一个点集（比如全部 n 次单位根，或者电路里的 n 个「行号」）。 零点多项式是「在 H 上全为 0、在别处不为 0」的那个多项式：

ZH(x) = Πh ∈ H ( x − h ) 每个点配一个因式，乘起来。H 有几个点，次数就是几

当 H = {1, ω, ω², …, ωn−1}（全部 n 次单位根）时，它会化简成一个极简的形式：

ZH(x) = xn − 1 因为 xn − 1 的根恰好就是全部 n 次单位根 —— 和 00 · 04 完全接上了

它为什么是「约束」的核心

现在把三件事串起来：

1

我要证明：某个多项式 f 在 H 的每个点上都是 0

直接检查 n 个点，代价是 O(n)。验证者不想干这个。

2

换一个说法

由因式定理（00 · 04）：f 在每个 h 上为 0 ⟺ 每个 (x − h) 都整除 f。 而不同的 (x − h) 之间没有公因式（两两互素），所以等价于把它们全乘起来、再整除 f。

3

于是一句话搞定

ZH(x) 整除 f(x)  ⟺  f 在 H 上全为 0。
而「整除」只要检查一件事：商 q(x) = f(x) / ZH(x) 是不是一个合法的多项式 （没有余数）。

4

再把它变成一个点上的检查

验证者随机挑一个点 ζ，要求证明者给出 q(ζ)， 然后验算 f(ζ) = q(ζ) · ZH(ζ)。
n 次检查变成了 1 次检查，靠的是 Schwartz–Zippel（01 · 09）。

✓
这就是 QAP 的全部骨架

02 · 01 后面的「从 R1CS 到 QAP」做的就是这个： 把「n 条约束都成立」编码成「某个多项式能被 ZH 整除」。
你现在已经知道它要干什么了，剩下的细节只是「怎么编码」。

10小结与常见误区

你应该带走的

  • 环 = 两个运算 + 分配律。乘法不要求可逆。
  • 域 = 环 + 非零元全可逆。四则运算齐全。
  • 合数模会产生零因子（3×4≡0 mod 12），导致约分失效、多项式根数失控。
  • 素数模 ⟺ 无零因子 ⟺ 构成域。三者等价。
  • 域的三大赠品：无零因子、n 次多项式至多 n 根、n+1 点唯一确定 n 次多项式。ZKP 全靠这三条。
  • 扩域 𝔽p² 就是把 ℝ→ℂ 的套路搬到有限域上，元素是「一对数」。
  • 特征 p 意味着 p = 0，且 (a+b)p = ap+bp。
  • 多项式乘法次数相加：deg(fg) = deg f + deg g。次数是 ZKP 里最贵的资源。
  • 零点多项式 ZH(x) = Π(x−h) 在 H 上全为 0；ZH 整除 f ⟺ f 在 H 上全为 0。QAP 的骨架就是这一句。
✕「环就是圆圈，域就是范围。」
✓
这两个词都是历史遗留的名字（ring / field），和几何形状毫无关系。 field 是德语 Körper（「体」）的英译，ring 的来历说法不一、没有定论。 当成纯粹的名字记住，别去联想画面。
✕「ℤ 是域，因为它能做加减乘。」
✓
ℤ 是环，不是域。因为 1/2 不在 ℤ 里 —— 除法不封闭。 「能做除法」的意思是「结果还在集合内」，不是「我能写出这个式子」。
✕「𝔽9 就是模 9 的余数。」
✓
模 9 的余数（ℤ/9ℤ）不是域，因为 9 不是素数，有零因子。
但 𝔽9 确实存在 —— 它的元素是「一对模 3 的数」， 需要写成 𝔽3²，和 ℤ/9ℤ 完全是两个结构 （元素个数都是 9，但运算规则不同，后者不是域）。
规矩记死：记号 𝔽q 里 q 必须是素数幂。 所以 𝔽7、𝔽9、𝔽2¹²⁸ 都合法，而 𝔽12 不存在。
✕「特征就是域里元素的个数。」
✓
特征和大小是两回事。𝔽p¹² 有 p¹² 个元素，但特征还是 p。 大小是「有多少个」，特征是「1 加几次归零」。
