线性代数：ZKP 真正的工作语言

如果说「群」是密码学的语言，「线性代数」就是电路和算术化的语言。 02 · 01 一页里出现了 28 次矩阵和向量，02 · 11 的核心叫「内积论证」。 这一页把向量、内积、矩阵、秩全部拆开 —— 从「向量是一串数」开始。

02 层硬门槛 ≈ 22 min 难度 3 / 5 前置：00 · 01 ～ 00 · 03 被用于：算术化 · 内积论证 · 折叠方案 · Sumcheck

01这一页要解决什么

下面这两句话，是你在 02 层会反复撞到的：

「电路被编译成三个 m×n 的矩阵 A、B、C，和一个长度 n 的向量 w。」
「每条约束长成 ⟨ai, w⟩ · ⟨bi, w⟩ = ⟨ci, w⟩。」 这两句话如果不拆，02 · 01 后面 80% 的内容都读不了

拆开之后一共只有五个词要懂：

词一句话在 ZKP 里干什么
向量一串排好序的数存所有变量的取值（w 就是「见证」）
内积两个向量逐位相乘再相加算「一个线性组合等于多少」
矩阵一堆行向量叠起来存整个电路的结构（哪些变量参与哪条约束）
线性组合一堆向量各乘系数再加起来ZKP 里所有约束的本质都长这样
秩矩阵里真正独立的信息有几行解释「为什么 R1CS 每条只能有一次乘法」
i
先给个定心丸

这一页不需要你会解线性方程组，也不需要行列式、特征值、矩阵求逆。 ZKP 用到的线性代数只有「加、乘、求和」三件事，剩下的都是这三件事的组合。 市面上线性代数教材里 80% 的内容，这里用不上。

02向量：一串排好序的数

忘掉中学物理里的「箭头」。在密码学里，向量就是一串数，仅此而已。

v = ( v1, v2, v3 )   比如   v = ( 3, 7, 1 ) 括号里的数叫「分量」。下标从 1 开始（论文里也常见从 0 开始）

长度是几，就叫几维向量。上面的 v 是三维的。 如果所有分量都在 𝔽p 里，就叫「𝔽p 上的向量」—— ZKP 里的向量全是这种，每个分量都是模 p 的余数。

和「集合」的区别：有序，而且能重复

集合 {…}向量 (…)
顺序有意义吗没有。{1,2} = {2,1}有。(1,2) ≠ (2,1)
能重复吗不能。{1,1} 就是 {1}能。(1,1) 是合法的二维向量
长度固定吗不固定固定，维度是整个空间的约定

这两个区别在 02 · 03 的 lookup 论证里非常关键 —— 那里要区分「集合相等」和「多重集相等」。

两种运算：加法和数乘

两个向量相加，就是逐位相加。一个数乘一个向量，就是每个分量都乘。

( 1, 2, 3 ) + ( 4, 5, 6 ) = ( 5, 7, 9 )   ← 逐位相加
2 · ( 1, 2, 3 ) = ( 2, 4, 6 )   ← 每个分量都乘 2
( 1, 2, 3 ) − ( 4, 5, 6 ) = ( −3, −3, −3 )   ← 减法就是加逆元

注意最后一行：减法不是新运算，是「加上负向量」。这和 00 · 02 里「群只有加法，减法靠逆元」是同一件事。

✓
长度 n 的向量，配上加法，就是一个群

封闭（加完还是 n 维）、结合、单位元是零向量 (0,…,0)、每个向量有逆元（取负）。 而且可交换 —— 所以是阿贝尔群，记作 𝔽pn。
这就是为什么 02 · 06 折叠方案里可以直接写 u + v，不需要解释。

03内积：把两个向量压成一个数

这是本页最重要的一个运算。它吃两个同长度的向量，吐一个数。

⟨ a, b ⟩ = a1b1 + a2b2 + ⋯ + anbn = Σi aibi 逐位相乘，然后全加起来。也叫「点积」「内积」，英文 inner product / dot product

手算一个：

a = ( 2, 0, 3 ) ， b = ( 1, 5, 4 )
⟨a,b⟩ = 2×1 + 0×5 + 3×4 = 2 + 0 + 12 = 14 注意中间那一项：0×5 = 0，直接消失。这就是「稀疏」的意思

三条必须记住的性质

性质写法
对称⟨a,b⟩ = ⟨b,a⟩。交换顺序结果一样
对第一项线性⟨a+b, c⟩ = ⟨a,c⟩ + ⟨b,c⟩，⟨ka, b⟩ = k⟨a,b⟩
退化性⟨a,a⟩ = 0 当且仅当 a 是零向量

第二条「线性」是全部关键。它意味着内积可以拆开、可以提系数 —— 所以当你看到 ⟨a, w⟩ 时，可以把它理解成「用 a 里的系数，把 w 的分量加权求和」。

i
在 ZKP 里，内积就是「一条约束左边等于多少」

02 · 01 里的 ⟨ai, w⟩，ai 是矩阵第 i 行的系数， w 是所有变量的取值。内积算出来的就是「第 i 条约束的左边那个线性表达式，代进具体取值后等于多少」。
比如 ai = (1, 0, 3, 0)，w = (x, y, z, t)， 那 ⟨ai, w⟩ = x + 3z。系数为 0 的项自动消失，正好对应「这个变量不参与这条约束」。

为什么 02 · 11 要专门叫「内积论证」

因为 Bulletproofs 的核心问题是：如何在不暴露 a、b 的前提下，证明我知道 ⟨a,b⟩ = v。 整个协议就是在「把内积拆成两半、递归折半」上做文章，最后证明大小只有 O(log n)。 不懂内积是什么，那一页从标题开始就是天书。

04矩阵：一堆行向量叠起来

矩阵没有神秘之处 —— 它就是把若干个同样长度的向量，一行一行摞起来。

A = 1   0   3
0   2   1 这是一个 2×3 矩阵：2 行、3 列。第一行是向量 (1,0,3)，第二行是 (0,2,1)

「m × n」读作「m 行 n 列」。先写行数，再写列数 —— 这个顺序别记反，论文里所有矩阵都是这么标的。

叫法长什么样在 ZKP 里的对应
行向量矩阵的一行，横着一条约束的系数 ai
列向量矩阵的一列，竖着一个变量在所有约束里的系数
方阵行数 = 列数较少见（ZKP 里 m ≠ n 是常态）
零矩阵全是 0某条约束不涉及某个乘数时的占位

矩阵乘向量：对每一行做一次内积

这是唯一需要记的矩阵运算。A·w 的结果是一个向量，长度等于 A 的行数：

A·w 的第 i 个分量 = ⟨A 的第 i 行 , w⟩ 就这么一句。矩阵乘向量 = 把每一行拎出来和内积一遍，结果排成一个新向量

手算：

A = [ 1 0 3 ; 0 2 1 ]  ,  w = ( 2, 5, 1 )

第 1 行： ⟨(1,0,3), (2,5,1)⟩ = 1×2 + 0×5 + 3×1 = 5
第 2 行： ⟨(0,2,1), (2,5,1)⟩ = 0×2 + 2×5 + 1×1 = 11

所以 A·w = ( 5, 11 )

这个 (5, 11) 就是「A 的两行各自的内积值」—— 也就是两条约束里第一个因子算出来是多少（不是整条约束左边）。 02 · 01 里的 A·w、B·w、C·w，就是三个矩阵各自做一遍这个操作。

!
形状对不上就乘不了

m×n 的矩阵只能乘长度为 n 的向量，结果长度是 m。
写论文时如果看到 A ∈ 𝔽pm×n、w ∈ 𝔽pn， 就是在声明这个匹配关系。形状不匹配的乘法在数学上没有定义，不是「算出来是零」。

05线性组合：一个你可能已经会了的词

「线性组合」听起来很学术，其实就是「各乘一个系数，再全加起来」。

c1v1 + c2v2 + ⋯ + ckvk c 是系数（标量），v 是向量。结果还是一个向量

你其实已经见过它两次了：向量加法是「系数全是 1」的线性组合； 而内积可以看成一个「结果退化成单个数字」的线性组合 —— 系数取自另一个向量，加完之后不再是个向量，而是一个数。

为什么 ZKP 里到处是这个词

因为电路里每一条约束，本质都是一个线性组合等于另一个线性组合。 看一个具体例子，约束是 x · y = z，其中 x、y、z 是三个变量：

令 w = ( 1, x, y, z )   ← 第 0 位固定是 1，方便表达常数项
a = ( 0, 1, 0, 0 )  ⟹  ⟨a,w⟩ = x
b = ( 0, 0, 1, 0 )  ⟹  ⟨b,w⟩ = y
c = ( 0, 0, 0, 1 )  ⟹  ⟨c,w⟩ = z

约束就是： ⟨a,w⟩ · ⟨b,w⟩ = ⟨c,w⟩  ⟺  x·y = z

看到了吗？「x 乘 y 等于 z」这条约束，被写成了三个内积。 系数里那些 0，就是「这个变量不参与」。

再复杂一点，如果约束是 (x + 3z) · (2y + 1) = x，那系数会变成 a = (0,1,0,3)、b = (1,0,2,0)、c = (0,1,0,0)。 无论表达式多长，只要它是「线性的」，就能塞进一个行向量里。 这里的「线性」指变量只以一次方出现 —— 可以有 3z、−7y， 但不能有 x·y 或 x²。出现乘积，就必须单独开一条约束。

✓
这就是「算术化」的全部内容

把一个程序（加减乘、赋值、条件）翻译成「一堆 ⟨a,w⟩·⟨b,w⟩ = ⟨c,w⟩」的形式， 就叫 R1CS 算术化。翻译过程是工程，但目标形式就是这个式子。 02 · 01 会用一整页做这件事，你现在已经知道它要做什么了。

06秩：一条约束为什么只装得下一个乘法

这一节是 02 · 01 第 6 节「为什么不能有高次项」的数学解释。 如果读着吃力，可以先跳过，记住结论就行。

先看「外积」：一个向量乘一个向量，得到一个矩阵

前面讲的内积是「向量 × 向量 = 数」。外积是反过来：「向量 × 向量 = 矩阵」。

u = ( 1, 2 )  ,  v = ( 3, 4 )

u ⊗ v = [ 1×3   1×4 ; 2×3   2×4 ] = [ 3   4 ; 6   8 ] 第 i 行第 j 列 = ui · vj。就这么直接

秩：这个矩阵里真正独立的有几行

看上面那个矩阵：[3, 4] 和 [6, 8]。 第二行正好是第一行的 2 倍 —— 它没有带来任何新信息。

秩 = 2  ：  两行真的独立
秩 = 1  ：  所有行都是同一行的倍数 秩就是「去掉冗余之后，还剩几行真正不同的」（对两行的矩阵而言，就是这两种情况）

外积得到的矩阵，秩永远是 1（只要 u、v 不是零向量）。 因为它的每一行都是 ui · v，都是同一个向量 v 的倍数。

矩阵秩为什么
[3, 4 ; 6, 8]1第二行 = 2 × 第一行，冗余
[1, 0 ; 0, 1]2两行完全独立，谁也凑不出谁
[2, 4 ; 3, 5]23/2 ≠ 5/4，不成比例
[1, 2, 3 ; 2, 4, 6]1第二行 = 2 × 第一行

把它接到 R1CS 上

每条 R1CS 约束是 ⟨a,w⟩ · ⟨b,w⟩ = ⟨c,w⟩。 左边是两个数相乘 —— 展开成「w 的二次型」时，二次项的系数矩阵恰好是 a 和 b 的外积。

二次项部分 = a ⊗ b   ⟹   秩恒为 1 所以每条 R1CS 约束只能承载「一个」二次项结构，不能塞进两个独立的乘法

这就是为什么写电路时，一行里出现两个乘法必须拆成两条约束。 不是因为编译器笨，是因为秩只有 1，装不下第二个。

!
这里我做了简化，说明一下

严格的秩定义是「列空间（或行空间）的维数」，需要先讲「张成」「线性无关」。 这一页只给了可操作的直觉：「成比例的几行算一行」。
这个直觉足以读懂 02 · 01 的论证，但如果你之后要看形式化证明， 需要补「线性无关」和「维数」的严格定义 —— 那部分暂时用不上，先欠着。

07手算：从两条约束到矩阵

把这一页的东西串一遍。电路里有三个变量 x, y, z，约束是： x·y = z、(x+1)·z = y。

1

定向量

变量向量 w = (1, x, y, z)，长度 4。第 0 位固定为 1，用来放常数。

2

第一条约束的系数

x·y = z：
a₁ = (0, 1, 0, 0) → ⟨a₁,w⟩ = x
b₁ = (0, 0, 1, 0) → ⟨b₁,w⟩ = y
c₁ = (0, 0, 0, 1) → ⟨c₁,w⟩ = z

3

第二条约束的系数

(x+1)·z = y：注意 x+1 里的 1 要用第 0 位表示。
a₂ = (1, 1, 0, 0) → ⟨a₂,w⟩ = 1 + x
b₂ = (0, 0, 0, 1) → ⟨b₂,w⟩ = z
c₂ = (0, 0, 1, 0) → ⟨c₂,w⟩ = y

4

堆成矩阵

两行摞起来，得到三个 2×4 的矩阵：
A = [0,1,0,0 ; 1,1,0,0]
B = [0,0,1,0 ; 0,0,0,1]
C = [0,0,0,1 ; 0,0,1,0]

5

代一组具体值验算

取 x=2, y=3, z=6（满足 x·y=z），则 w = (1,2,3,6)。
A·w 第 1 行：0·1+1·2+0·3+0·6 = 2（= x ✓）
B·w 第 1 行：0+0+1·3+0 = 3（= y ✓）
C·w 第 1 行：0+0+0+1·6 = 6（= z ✓）
检查 2 × 3 = 6 ✓ 第一条约束成立。

6

验第二条

A·w 第 2 行：1·1 + 1·2 + 0 + 0 = 3（= x+1 ✓）
B·w 第 2 行：0+0+0+1·6 = 6（= z ✓）
C·w 第 2 行：0+0+1·3+0 = 3（= y ✓）
检查 3 × 6 = 18 ≠ 3 —— 第二条不成立。

✓
注意第 6 步的结果

约束不成立，说明 x=2, y=3, z=6 这组赋值不是合法见证。 但注意：x·y=z 是满足的。真正卡住的是第二条 (x+1)·z=y， 代进去是 3×6=18，而右边是 3。
这正是验证者要检查的东西：不是「你觉得对不对」，而是每个内积算出来、再逐条比对。
只要有一条不成立，整组赋值就被拒绝 —— 验证者不需要知道你错在哪一条，也不能被你「大部分都对」说服。

08小结与常见误区

你应该带走的

  • 向量 = 一串有序、可重复的数。和集合的区别是「有序」和「可重复」。
  • 内积 ⟨a,b⟩ = Σaᵢbᵢ：两个向量 → 一个数。满足对称、线性、退化性。
  • 矩阵乘向量 = 对每一行做内积，结果是向量。m×n 只能乘长度 n 的向量。
  • 线性组合 = 各乘系数再加起来。电路里每条约束都是「线性组合 × 线性组合 = 线性组合」。
  • 秩 = 去掉成比例的行之后还剩几行。外积的秩恒为 1，这解释了为什么一条 R1CS 只能有一个乘法。
  • 整套算术化就是：把程序翻译成一堆 ⟨a,w⟩·⟨b,w⟩ = ⟨c,w⟩。
✕「向量就是带箭头的线段，有方向和长度。」
✓
那是物理里的几何向量，只是一种可视化方式。 这里用的是「一串数」，没有箭头、没有长度概念（因为 𝔽p 里没有大小顺序）。 画成箭头只是为了帮助想象，别把它当定义。
✕「内积和外积是一对反运算。」
✓
不是。它们输入输出类型都不同： 内积是「向量 × 向量 → 数」，外积是「向量 × 向量 → 矩阵」。 没有互逆关系，只是名字对仗。
✕「矩阵乘法就是对应位置相乘。」
✓
那是逐元素乘（Hadamard 积），符号是 ⊙。 普通矩阵乘法的规则是「行 × 列做内积」，完全不同。论文里两种都会出现，看符号区分。
✕「秩越大越好 / 越小越好。」
✓
没有好坏，是结构约束。 在 R1CS 里秩 ≤ 1 是被迫的（因为一条约束只容一个乘法）， 在矩阵编码里秩小反而意味着压缩率高。看语境。
