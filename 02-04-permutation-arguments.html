置换论证：证明两个格子装的是同一个变量

R1CS 靠矩阵的列天然保证「同一个变量出现在多条约束里」。PLONK 把电路摊成表格之后， 这种保证消失了 —— 第 3 行第 1 列和第 7 行第 2 列可能是同一个值，但表格不知道。 置换论证就是把这个「知道」补回去。

≈ 15 min 难度 3 / 5 前置：查找论证 · 多项式承诺 后续：PLONK 证明系统

01这个模块要解决什么问题

PLONK 把电路写成一张表：每行一个门，每列一类信号。这张表比 R1CS 灵活得多， 但也丢了一个关键性质 —— 「同一列 = 同一变量」这个隐含约定没了。

看个例子。下面两条约束在 PLONK 里可能是这样摆的：

行左输入 a右输入 b输出 c门类型
1xxv₁乘法
2v₁xv₂乘法

第 1 行的 a 和第 2 行的 b 都是 x，它们必须是同一个值。 但表格只是两个独立的格子。如果不用额外机制绑定，证明者可以让第 1 行填 3、第 2 行填 5， 两条约束各自都成立，可它们描述的已经不是同一个 x 了。

!
这不是理论问题

缺少 copy constraints 的 PLONK 电路，等价于「每个信号都是自由变量」—— 证明者可以给同一个逻辑变量的不同出现赋不同的值。整个电路语义彻底崩掉， 而所有约束检查依然通过。

02直觉：给每个格子发一张「身份证」

我们希望表达的是：「a₁ 和 b₂ 是同一个值」。 换个说法：如果给每个格子一个编号，那么「值相等的那些格子」构成一个循环 —— 沿着这个循环走一圈，会回到起点。

这正是置换：一个把位置映射到位置的函数，且是一一对应的。 证明「这些格子值相等」，等价于证明「存在一个置换 σ，使得每个格子的值等于它映射到的那一格的值」。

wi = wσ(i)   对所有 i w 是按位置展开的见证向量；σ 是公开的置换，由电路布线决定

注意 σ 是公开且固定的：它就是电路的连线表。证明者不能改它， 只能证明「我的赋值满足这个置换关系」。

03置换 σ 长什么样

把表格按行优先展平成一维，每个格子有一个下标：

w = ( a1, b1, c1, a2, b2, c2, … ) 下标 0,1,2,3,4,5,… 分别对应第 1 行的 a/b/c、第 2 行的 a/b/c

假设要声明「a₁（下标 0）= b₂（下标 4）= a₃（下标 6）」， 那么 σ 在这三个位置上形成一个循环：

σ:  0 → 4,   4 → 6,   6 → 0 其余位置 σ(i) = i（自己映射到自己，表示不与其他格子共享）

于是「值相等」的条件变成：w₀ = w₄、w₄ = w₆、w₆ = w₀。 循环闭合，三个格子自然相等。

σ 的完整定义

符号含义
σ一个置换，σ: {0,…,n−1} → {0,…,n−1}，双射。由电路的变量复用关系决定。
σ(i) = i该位置不与其他位置共享，是「自由」的。
循环结构σ 分解成若干个不相交的循环，每个循环对应「一个逻辑变量的所有出现」。

所以置换论证要证的是：对每个循环，环上所有位置的取值相同。 而「环上取值相同」等价于「取值向量 w 在 σ 下不变」，也就是 w = w ∘ σ。

σ 是怎么从电路里生成出来的

σ 不是手写的，是编译器根据「哪些格子引用同一个变量名」自动生成的。 伪代码只有十行： 

# 输入：cells = [{'row': r, 'col': c, 'name': 'x'}, ...]
# 输出：sigma，长度 n 的置换数组

n = len(cells)
sigma = list(range(n))          # 默认每个位置映射到自己

groups = {}                      # 按变量名分组
for i, cell in enumerate(cells):
    groups.setdefault(cell['name'], []).append(i)

for name, idxs in groups.items():
    if len(idxs) < 2: continue    # 只出现一次，不需要置换
    for k in range(len(idxs)):
        i = idxs[k]
        j = idxs[(k + 1) % len(idxs)]   # 环状连接
        sigma[i] = j

# 例：x 出现在位置 0、4、6 → sigma[0]=4, sigma[4]=6, sigma[6]=0

注意最后那个 % len(idxs)：它让最后一个回到第一个，形成闭环。 如果用链式连接（最后一个映射到自己），累乘检查时首尾对不上，验证会失败。

04怎么证：又是累乘，但这次带 σ

直接逐对检查 wi = wσ(i) 要 n 条约束。 和查找论证一样，这里也用「随机指纹 + 累乘」把它压成一条。

第一步：给每个位置打指纹

取随机挑战 β, γ，对位置 i 定义两个量：

分子：wi + β · i + γ      分母：wi + β · σ(i) + γ 分子绑定「值 + 自己的位置」，分母绑定「值 + 它映射到的位置」

为什么要带位置 i？因为只比 wi 会漏掉「多个不同的值恰好凑成相同多重集」的情况。 把位置混进去，等于给每个格子一个唯一标签，防止交叉作弊。

第二步：连乘并检查闭合

Πi=0n−1 ( wi + β·i + γ ) = Πi=0n−1 ( wi + β·σ(i) + γ ) 如果 w 在 σ 下不变，两边是同一组因子的重新排列，乘积必然相等

反过来，如果某个循环上出现了不一致（比如 w₀=3 但 w₄=5）， 两边的因子集合就不同，乘积相等的概率可以忽略。

i
为什么「重排」能让乘积相等

因为乘法可交换。左边是 f(0), f(1), …, f(n−1) 的乘积， 右边是同一批因子按 σ 重排后的乘积 —— 只要 w 满足 wi = wσ(i)， 每个因子都一模一样，顺序无关。这就是置换论证能用「一个等式」表达 n 条约束的原因。

05PLONK 里的 z(x)：把连乘变成多项式

和查找论证的 Z 一样，PLONK 引入一个累乘多项式 z(x)， 在单位根 gi 上的取值就是「到第 i 行为止的累乘」：

z(g0) = 1,    z(gi+1) = z(gi) · ( wi + β·i + γ ) / ( wi + β·σ(i) + γ ) 每一行乘一个分子、除一个分母；走完 n 行后检查 z(gn) = 1

因为 gn = 1（单位根回到起点），所以 z(gn) = z(g0) = 1。 这个「首尾闭合」就是置换成立的证据。

完整的 PLONK 约束里它长什么样

PLONK 的置换约束是一个跨行的等式，形如：

z(g·x)·( w(x) + β·x + γ ) = z(x)·( w(x) + β·σ(x) + γ ) 其中 w(x) 是信号多项式，σ(x) 是置换多项式，都在单位根上取值

注意 g·x 表示「下一行」。这一条等式同时编码了「逐行递推」和「跨行相等」两件事 —— 它是 PLONK 里唯一一条不是「单行内」的约束。

✓
代价

多了三个多项式：z(x)、σ1(x)、σ2(x)（左右两列各一个）。 每个都要承诺，所以 PLONK 的证明比 Groth16 大 —— 这是「表格灵活性」的票价。

06一个手算示例

取一个极小的电路，4 个位置，其中位置 0 和位置 2 是同一个变量 x。

w = ( 7, 3, 7, 9 )     σ = ( 2, 1, 0, 3 ) σ(0)=2、σ(2)=0 形成循环 {0,2}；σ(1)=1、σ(3)=3 是自环

取 β = 2, γ = 1，逐项算因子：

iwiσ(i)分子 = wi+βi+γ分母 = wi+βσ(i)+γ
0727+0+1 = 87+4+1 = 12
1313+2+1 = 63+2+1 = 6
2707+4+1 = 127+0+1 = 8
3939+6+1 = 169+6+1 = 16

两边的乘积：

左边 = 8 × 6 × 12 × 16 = 9216
右边 = 12 × 6 × 8 × 16 = 9216   ✓ 相等

注意 i=0 和 i=2 的分子分母正好互换了 —— 这正是循环 {0,2} 的体现。 而 i=1, i=3 的分子分母相同（自环），乘上去不改变结果。

如果有不一致会怎样

把 w₂ 改成 8（但 w₀ 仍是 7）：

左边 = 8 × 6 × (8+4+1) × 16 = 8 × 6 × 13 × 16 = 9984
右边 = 12 × 6 × (8+0+1) × 16 = 12 × 6 × 9 × 16 = 10368

9984 ≠ 10368，检查失败。一个位置的偏差就会让整个连乘对不上。

07为什么 R1CS 不需要它

这不是「R1CS 更先进」，而是表示方式不同带来的必然差异。

维度R1CSPLONKish
变量的表示见证向量的一个分量，按列索引表格里的一个格子，按行列定位
同一变量多次出现自然由「同一列」保证需要显式的置换约束
表达力弱：只能一次乘法强：自定义门 + 查找表
额外开销无3 个多项式 + 1 条跨行约束

换句话说：R1CS 把「变量」和「位置」绑死了，所以不用额外证明； PLONK 把两者解耦了，换来灵活性，代价是要自己把绑定关系证回来。

08小结与常见误区

你应该带走的

  • PLONK 把电路摊成表格后，「同一变量」不再由结构保证，必须显式证明。
  • 置换 σ 是公开的、由电路布线决定的双射，它把同一变量的所有出现连成循环。
  • 证明方式：Π(wi+βi+γ) = Π(wi+βσ(i)+γ)，靠乘法可交换性。
  • 带位置 i 是为了防止不同值的多重集恰好相同。
  • PLONK 用累乘多项式 z(x) 把 O(n) 条约束压成一条跨行等式。
✕「置换论证是 PLONK 独有的。」
✓
任何位置化的算术化方案都需要它 —— Halo2、Marlin、UltraPLONK 都有。 只有 R1CS 这类「变量即列」的方案才天然免疫。
✕「σ 是证明者生成的，他可以为所欲为。」
✓
σ 由电路编译结果决定，是验证密钥的一部分，公开且固定。 证明者只能证明「我的赋值满足这个 σ」，不能挑一个对自己有利的 σ。
✕「只要每个门单独满足约束，整体就对了。」
✓
这是最危险的误解。门内约束 + 置换约束才构成完整电路。 缺了置换，每个门都能独立通过，但门与门之间的连线全断了 —— 电路退化成 n 个互不相关的等式。
✕「置换论证和查找论证是一回事。」
✓
两者都用「多重集指纹 + 累乘」，但目标不同：查找证的是「我的值来自那张表」， 置换证的是「我的值在某个位置映射下不变」。数学工具同源，语义完全不同。
