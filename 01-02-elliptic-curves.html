椭圆曲线：把「加法」定义在曲线点上

有限域给了我们一个能做加减乘除的圈。椭圆曲线在这个圈上再叠一层结构： 曲线上的点可以「相加」。这个加法是单向函数的来源 —— 正着算容易，倒着算几乎不可能。

核心基础 ≈ 14 min 难度 3 / 5 前置：00 · 02 群 · 有限域 被用于：承诺 · 配对 · 签名

01这个模块要解决什么问题

有限域本身是一个「可逆」的结构：知道 a·b = c，很容易反推出 a。 密码学需要的是单向函数 —— 正着算便宜，倒着算不可能。

椭圆曲线提供了这种单向性。它的核心运算叫「标量乘法」：

P  →  k·P = P + P + ⋯ + P  ( k 次 ) 给定 P 和 k，算出 kP 很快（O(log k) 次点加）；给定 P 和 kP，求 k 极难

这个「极难」就是离散对数问题（ECDLP）。 所有基于椭圆曲线的密码学 —— 签名、承诺、KZG、Groth16 —— 安全性都建立在它之上。

i
为什么不用 RSA 那套（大整数分解）

同样的安全强度下，椭圆曲线的密钥短得多：256 位椭圆曲线 ≈ 3072 位 RSA。 密钥短意味着群元素小、证明小、链上存储便宜 —— 这对 ZKP 是决定性的。

02直觉：两点连线，交曲线于第三点

椭圆曲线有一个几何性质：任意一条直线与曲线最多交于三个点 （三次方程最多三个根）。利用这个性质，可以定义一种「加法」：

1

过 P 和 Q 画一条直线

这条直线会与曲线交于第三个点，记为 R'。

2

把 R' 沿 x 轴翻折

得到 R，定义 P + Q = R。

3

如果 P = Q，用切线

两点重合时，直线退化成切线，同样交于第三点，再翻折 —— 这就是「倍点」。

这个定义的妙处：它满足交换律和结合律，而且存在单位元（无穷远点）和逆元（关于 x 轴翻折）。 于是曲线上的点构成一个阿贝尔群。

✓
为什么「翻折」这一步不能省

如果不翻折，直接取第三点，加法就不满足结合律 —— (P+Q)+R ≠ P+(Q+R)。 翻折保证了群公理成立。这个细节在纯代数公式里体现为 y₃ 前面那个负号。

03曲线方程与点

ZKP 里用的几乎都是「短 Weierstrass 形式」：

y² = x³ + a·x + b   ( mod p ) a、b 是曲线参数；要求 4a³ + 27b² ≠ 0（否则曲线有奇点，不成群）

曲线上的「点」就是满足这个方程的一对 (x, y)，再加上一个特殊的无穷远点 O （作为加法单位元，相当于零）。

符号含义
𝔾曲线上的所有点构成的群，元素个数叫「曲线阶」，记作 #𝔾。
O无穷远点，单位元。P + O = P。
−PP=(x,y) 的逆元，即 (x, −y)。所以 P + (−P) = O。
n子群的阶（通常是一个大素数），决定安全强度。
G生成元，子群里所有点都能写成 k·G。
r标量域的阶，也就是「k 的取值范围」，通常与 n 同量级。

Hasse 定理：曲线阶大概是多少

| #𝔾 − ( p + 1 ) | ≤ 2√p 曲线阶总是接近 p+1，误差不超过 2√p —— 这保证了群足够大

04点加法的公式（工程里真正在跑的东西）

几何直觉很好，但代码里用的是代数公式。所有运算都在 𝔽p 里，除法 = 乘逆元。

两个不同的点相加：P + Q

斜率：λ = ( y2 − y1 ) / ( x2 − x1 )
横坐标：x3 = λ² − x1 − x2
纵坐标：y3 = λ( x1 − x3 ) − y1 结果点 (x₃, y₃) 必然仍在曲线上

同一个点相加（倍点）：2P

斜率：λ = ( 3x1² + a ) / ( 2y1 )
之后的公式与上面完全相同 这是对曲线方程两边求导得到的切线斜率
!
两种退化情况必须单独处理

① P = −Q（x 相同、y 相反）：结果是无穷远点 O，公式里的分母为 0。
② y = 0 的点做倍点：分母 2y = 0，同样失效，结果是 O。

实现里如果不处理这两种情况，会出现除以零。这也是侧信道攻击的常见入口点。

05标量乘法与离散对数

标量乘法就是反复做点加。k·P 用「倍加算法」（double-and-add）只要 O(log k) 次点运算：

把 k 写成二进制 k = ( bm…b1b0 )2
从高位往低位：每步先倍点，若当前位为 1 再加 P 例：k=13=1101₂ → 2P, 3P, 6P, 7P, 13P（4 次倍点 + 3 次加法）

单向性来自哪里

已知 P 和 k  ⟹  算 k·P  ：O(log k) 次运算，毫秒级
已知 P 和 Q = k·P  ⟹  求 k  ：最好的算法是 O(√n) 次 n 是子群阶。n ≈ 2²⁵⁴ 时，√n ≈ 2¹²⁷，宇宙年龄也算不完

这个不对称就是一切的基础。注意「最好算法是 O(√n)」—— 这就是为什么 256 位曲线只提供 128 位安全强度，因为攻击复杂度是开平方的。

i
「128 位安全」是什么意思

指攻击者需要约 2¹²⁸ 次运算才能破解。作为对比，全球算力总和大约在 2⁸⁰ 量级。 所以 128 位是当前工程上的标准强度，256 位曲线刚好够。

06曲线参数怎么选：BN254 vs BLS12-381

ZKP 里 99% 的场景只用这两条曲线。它们的差别很具体：

维度BN254（alt_bn128）BLS12-381
基域大小254 位381 位
安全强度约 100–110 位（偏弱）约 128 位（标准）
嵌入度1212
2-adicity约 2832
以太坊支持原生预编译（EIP-196/197）无原生支持，需合约实现
典型使用者Groth16、PLONK 上链验证Zcash、Filecoin、BLS 签名

选型逻辑很现实：要上以太坊主网验证，几乎只能用 BN254，因为它的配对运算有预编译合约， gas 便宜一个数量级。BLS12-381 更安全，但在 EVM 里实现配对要几十万 gas。

!
BN254 的 100 位安全强度是个真实隐患

它的基域只有 254 位，理论上 NFS 类算法能把它降到约 100 位强度。 对短期有效的证明（Rollup 批次）问题不大，但对长期存档的证明，应该考虑迁移到 BLS12-381 或透明方案。

07手算一条小曲线

取 p = 7，曲线 y² = x³ + 2x + 3 (mod 7)。先枚举所有点：

xx³+2x+3 mod 7是平方剩余吗对应的 y
03否—
16否—
21是（1²=1）1, 6
31是1, 6
45否—
55否—
60是（0²=0）0

平方剩余指「某个数的平方模 p 之后能得到它」。模 7 的平方剩余是 {1, 2, 4}。

所以曲线上一共 5 个点：(2,1), (2,6), (3,1), (3,6), (6,0)，加上无穷远点 O，群阶为 6。

算一次 P + Q

取 P = (2,1)、Q = (3,1)：

λ = ( 1 − 1 ) / ( 3 − 2 ) = 0
x3 = 0² − 2 − 3 = −5 ≡ 2 ( mod 7 )
y3 = 0·( 2 − 2 ) − 1 = −1 ≡ 6 ( mod 7 )

所以 P + Q = (2, 6)。验证 (2,6) 在曲线上：36 = 8+4+3 = 15 ≡ 1 (mod 7) ✓

算一次倍点 2P

取 P = (2,1)，a = 2：

λ = ( 3·2² + 2 ) / ( 2·1 ) = 14 / 2 = 7 ≡ 0 ( mod 7 )
x3 = 0 − 4 = −4 ≡ 3
y3 = 0 − 1 = −1 ≡ 6

所以 2P = (3, 6)。在这个玩具例子里，「给定 P 和 2P 求 2」一眼就能看出来； 但在 254 位的曲线上，这就是不可能完成的任务。

08小结与常见误区

你应该带走的

  • 椭圆曲线上的点构成阿贝尔群，加法由「弦与切线」定义。
  • 标量乘法 kP 是单向函数：正算 O(log k)，反算 O(√n)。
  • 256 位曲线 ≈ 128 位安全强度，因为攻击复杂度是开平方的。
  • BN254 胜在以太坊原生支持，BLS12-381 胜在安全强度。
  • 点加法有两种退化情况（P=−Q、y=0），实现必须单独处理。
✕「椭圆曲线加密和椭圆曲线方程是同一件事。」
✓
方程只是定义了点集。密码学用的是「点群上的离散对数问题」， 而不是方程本身。同一个方程换一个基域，安全性完全不同。
✕「曲线上的点越多越安全。」
✓
安全性取决于子群的阶是否为一个大素数，以及曲线是否抗各类攻击（如 MOV 攻击）。 一条阶为合数的曲线，可能被 Pohlig–Hellman 算法快速分解。
✕「标量乘法可以并行加速，所以不安全。」
✓
并行只能加速常数倍。离散对数的 O(√n) 是本质复杂度， 不存在已知的多项式算法（除非量子计算机用 Shor 算法）。
✕「ZKP 里的曲线和比特币的 secp256k1 一样。」
✓
完全不同。ZKP 需要配对友好的曲线（嵌入度 12）， secp256k1 的嵌入度是 1，做不了配对，也就做不了 KZG 和 Groth16。
