多项式与 FFT：ZKP 真正在算的东西

算术化把电路变成了约束，QAP 把它变成了多项式恒等式，KZG 承诺的也是多项式。 整个 ZKP 的算力，八成花在「多项式求值」和「点值 ↔ 系数转换」上。 这一页讲清楚这两件事为什么这么快、以及为什么快不了。

性能核心 ≈ 15 min 难度 3 / 5 前置：00 · 04 单位根 · 00 · 03 多项式 被用于：QAP · KZG · FRI

01这个模块要解决什么问题

多项式有一个别的对象没有的性质：两个不同的 d 次多项式，最多在 d 个点上相等。

这个性质（Schwartz–Zippel 引理的推论）意味着一件事：

「两个多项式完全相同」  ≈  「在随机点 z 上取值相同」 出错概率 ≤ d/p，p ≈ 2²⁵⁴ 时可忽略

于是「检查一亿条约束」变成了「检查一个等式在一个点上成立」。 这就是 SNARK 从 O(n) 降到 O(1) 的全部秘密。

而要做到这一点，必须能在两种表示之间自由切换： 系数形式（便于做加减乘）和点值形式（便于做批量检查）。 切换的工具，就是 FFT。

02同一个多项式的两种写法

表示形式擅长什么不擅长什么
系数形式
coefficient		 p(x) = c0 + c1x + … + cdxd 加法（逐项加）、乘法（卷积）、求导 批量求值（每个点 O(d)）
点值形式
evaluation		 (x0,y0), (x1,y1), … 批量求值（查表 O(1)）、逐点检查 加法要逐点加（简单）、乘法要逐点乘（简单）但插值回去很贵

关键洞察：如果我们只在同一组固定的点上求值， 那么「点值形式下的逐点乘」就等于「系数形式下的多项式乘」—— 而这正是把「约束的乘积」变成「可以批量检查的形式」所需要的。

( p · q )( xi ) = p(xi) · q(xi) 在点值形式下，多项式乘法就是逐点相乘 —— O(n) 而不是 O(n²)

03插值：从点回到系数

给定 n 个点，唯一确定一个次数小于 n 的多项式。构造它的公式叫拉格朗日插值。

p(x) = Σi yi · Li(x) ,    Li(x) = Πj≠i ( x − xj ) / ( xi − xj ) L_i 是「在第 i 个点上取 1、其余点取 0」的基函数
符号含义
yi第 i 个点上的目标取值
Li(x)拉格朗日基多项式，满足 Li(xj) = 1 当 i=j，否则为 0
分母常数，只依赖点的位置。预先算好可以复用

朴素插值是 O(n²)（每个 Li 要乘 n 项）。 但如果点在单位根上，可以做到 O(n log n) —— 这就是逆 NTT。

i
QAP 就是一次插值

算术化里把 R1CS 矩阵的每一列看成「在点 1…m 上的取值」， 插值出 Aj(x)、Bj(x)、Cj(x)。 这一步的复杂度直接决定证明生成时间。

04NTT：把 O(n²) 变成 O(n log n)

NTT（Number Theoretic Transform）是 FFT 在有限域上的版本。 名字不同，算法结构完全一样，只是把复数单位根换成了域里的单位根。

它算的是什么

Yk = Σj=0n−1 yj · ωjk 正向 NTT：系数 → 点值；逆向 NTT：点值 → 系数（用 ω⁻¹）
符号含义
ωn 次本原单位根：ωn = 1，且 ωk ≠ 1 对 0<k<n。
yj输入（系数或点值）
Yk输出（点值或系数）
n长度，必须是 2 的幂（为了做蝶形分解）

为什么能加速

把求和按奇偶下标拆成两半：

Yk = Ek + ωk · Ok ,    Yk+n/2 = Ek − ωk · Ok E 是偶数项的变换，O 是奇数项的变换；两者只算一次，被两个输出复用

递归下去，复杂度 T(n) = 2T(n/2) + O(n) = O(n log n)。 这就是「蝶形运算」的由来：每个输入被用两次，形状像蝴蝶。

05单位根从哪来：回到 2-adicity

NTT 需要一个 n 次单位根。而 𝔽p* 是循环群，阶为 p−1。 所以「存在 n 次单位根」等价于「n 整除 p−1」。

p − 1 = 2s · t   ⟹   支持所有 n ≤ 2s 的 NTT s 就是 2-adicity。n 超过 2^s，就没有对应的单位根，NTT 做不了

单位根怎么算

设 g 是 𝔽p* 的生成元，那么

ω = g(p−1)/n 因为 g 的阶是 p−1，升到 (p−1)/n 次方后，阶正好变成 n

实际实现会预先算好一张「单位根表」，避免每次重复求幂。 这张表的大小等于 n，是证明者内存占用的一部分。

!
这是电路规模被卡在 2 的幂上的真正原因

BN254 的 s ≈ 28，所以单个 NTT 最多处理 2²⁸ 个点。 更大的电路必须做「分段 NTT」或者换曲线 —— 不是软件优化能解决的。

06蝶形运算：一趟的数据流

以 n = 4 为例，输入 (y₀,y₁,y₂,y₃)，输出 (Y₀,Y₁,Y₂,Y₃)：

第一层（步长 1）：
  a0 = y0 + y1    a1 = y0 − y1
  a2 = y2 + y3    a3 = y2 − y3
第二层（步长 2，乘 ω）：
  Y0 = a0 + a2    Y2 = a0 − a2
  Y1 = a1 + ω·a3    Y3 = a1 − ω·a3

总共 n/2 × log₂n = 2 × 2 = 4 次蝶形，每次 1 次乘 + 2 次加减。 朴素 DFT 需要 n² = 16 次乘法。规模越大，差距越大。

n朴素 O(n²)NTT O(n log n)加速比
2¹⁰ ≈ 1 千~100 万~1 万100×
2²⁰ ≈ 100 万~10¹²~2×10⁷5 万×
2²⁴ ≈ 1600 万~2.8×10¹⁴~4×10⁸70 万×

07手算：三点插值

给定三个点 (0,1)、(1,3)、(2,7)，求过它们的二次多项式。

观察一下：p(x) = x² + x + 1 刚好满足。

p(0) = 1  ✓   p(1) = 3  ✓   p(2) = 7  ✓

用拉格朗日公式验证一下，先算三个基函数在 x=1 处的值：

L0(1) = (1−1)(1−2) / ((0−1)(0−2)) = 0
L1(1) = (1−0)(1−2) / ((1−0)(1−2)) = 1
L2(1) = (1−0)(1−1) / ((2−0)(2−1)) = 0

所以 p(1) = 1·0 + 3·1 + 7·0 = 3 ✓，和预期一致。

这个例子说明基函数的本质：每个 Li 只在第 i 个点上「选中」自己， 其余点全为零。所以插值就是「按权重把 y 值拼起来」。

08小结与常见误区

你应该带走的

  • 多项式有两种表示：系数形式（便于算）和点值形式（便于查）。
  • 在固定点集上，点值形式的乘法就是逐点相乘，O(n)。
  • NTT 用单位根把两种表示互转，复杂度 O(n log n)。
  • 单位根的存在依赖 n 整除 p−1，即 n ≤ 2s（s 是 2-adicity）。
  • 蝶形运算让每个中间结果被复用两次，这是加速的全部来源。
✕「FFT 只能处理浮点数。」
✓
FFT 是算法结构，域可以是复数、也可以是有限域。 有限域上的版本叫 NTT，没有浮点误差，结果精确 —— 这对密码学是必需的。
✕「多项式次数越高越好，表达力更强。」
✓
次数直接对应 NTT 规模和证明者内存。次数翻倍，证明时间也大约翻倍。 能用低次就用低次，这是电路优化的核心目标之一。
✕「插值和求值是一回事。」
✓
方向相反：求值是「给系数和点，算值」；插值是「给点和值，算系数」。 前者是 NTT，后者是逆 NTT。
✕「补零到 2 的幂没有代价。」
✓
代价很实在：一个 100 万约束的电路补到 2²⁰ 只浪费 5%， 但 110 万约束补到 2²¹ 就浪费了 47% —— 证明时间直接翻倍。 所以电路优化常常是在「凑整」上做文章。
